Platform Features

Everything you need to license and protect your software.

All the core authentication tools developers rely on, engineered with stronger cryptography and faster global delivery.

Flexible Authentication Flows

Support license-only login, username & password + key registration, subscription levels, custom key masks, and instant batch key generation.

License Keys Subscriptions Custom Masks

HWID Locking & Hash Checks

Bind seats to hardware fingerprints with configurable cooldown resets, verify binary SHA-256 hashes, and block modified clients automatically.

HWID Lock Binary Hash Check ATTESTATION

FIDO2 / YubiKey & Ephemeral Sessions

Protect your developer account with FIDO2 hardware keys and TOTP 2FA while every client session uses rotating Ed25519 + AES-256-GCM tunnels.

YubiKey WebAuthn ED25519

Cloud Variables, Files & Chats

Deliver encrypted server-side variables, authenticated binary downloads, and real-time in-app chat channels only to verified subscribers.

Encrypted Vars File Hosting In-App Chat

Blacklists, Whitelists & Webhooks

Block abusive IPs, HWIDs, and ASNs globally. Proxy external API requests through server-side webhooks so secrets never touch the client.

IP / HWID Bans Proxy Webhooks Audit Logs

Team & Reseller Management

Create scoped sub-accounts for managers and resellers with credit balances, key generation limits, and per-application permissions.

Reseller Credits Team RBAC OFFLINE LEASES
